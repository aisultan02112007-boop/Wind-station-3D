# Wind-station-3D

Учебный симулятор ветроэнергетики. Реализован этап 1: модель сухого воздуха, мощность турбины, слайдер ветра и график Canvas. Без зависимостей и сборки.

## Запуск

Из корня репозитория:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

В обычной локальной среде откройте `http://localhost:8000`. Открытие HTML через file:// не подходит для ES-модулей. В облачной настройке HTTP-запросы используются для внутренней проверки.

## Проверка

```sh
node --test tests/physics.test.mjs
```

Нужен Node.js 22 или новее (автоматическое распознавание ES-модулей). В браузере переместите слайдер: ниже 3 м/с мощность нулевая; при 8 м/с около 0,709 МВт; при 20 м/с 2 МВт; при 25 м/с защитная остановка. Клавиши стрелок должны менять значение при фокусе на слайдере.

Параметры турбины условные. Cp постоянный, механические и электрические потери не учтены, выше номинальной скорости TSR меняется без корректировки Cp. Это упрощённая кривая, а не аэродинамическая модель лопастей. При стандартной плотности 2 МВт достигаются примерно при 11,3 м/с; 12 м/с — отдельный порог ограничения оборотов. Точка ограничения мощности зависит от плотности. Функция сдвига ветра подготовлена отдельно; слайдер задаёт ветер непосредственно у ротора.
