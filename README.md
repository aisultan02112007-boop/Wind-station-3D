# Wind-station-3D

Учебный симулятор ветроэнергетики для браузера. Реализованы этапы 1–2: физическая модель, слайдер ветра, график мощности и сцена Three.js с турбиной на холмистой равнине. Лопасти вращаются по расчётной угловой скорости. Радиус ротора 40 м, высота ступицы 80 м; одна единица сцены равна метру.

## Запуск на своём компьютере

В терминале из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

На Windows с Python Launcher можно использовать `py -m http.server 8000 --bind 127.0.0.1`.
Откройте адрес `http://localhost:8000` в браузере на том же компьютере. Открытие HTML через file:// не подходит для ES-модулей. Облачный путь `/workspace/Wind-station-3D` относится только к облачной машине; для локальной работы клонируйте репозиторий на компьютер.

Three.js 0.186.1 включён в `vendor/three`: npm и сборка не нужны, все файлы загружаются с локального сервера. Версия, лицензия MIT, источник и контрольные суммы указаны в `vendor/three/README.md`. Других зависимостей приложения нет. Для 3D нужен современный браузер с WebGL 2 и import maps. Если 3D недоступно, расчёт и график продолжают работать.

## Управление

- Слайдер задаёт скорость ветра непосредственно на высоте ротора.
- Перетаскивание сцены поворачивает камеру; колесо мыши меняет масштаб.
- Под сценой есть кнопки поворота, масштаба и сброса камеры, доступные через Tab и Enter.
- «Пауза анимации» останавливает только визуализацию, расчёт продолжается. При системной настройке уменьшения движения анимация изначально на паузе; этой кнопкой её можно включить.
- В скрытой вкладке анимация приостанавливается. При нулевых оборотах или паузе сцена перерисовывается только по необходимости.

## Проверка

```sh
node --test tests/physics.test.mjs
```

Нужен Node.js 22 или новее. Проверки: плотность, кубический закон мощности, пороги, сдвиг ветра, недопустимые значения и переполнение, угловая скорость и её связь с RPM.

Проверка в браузере:

1. При 8 м/с мощность около 0,709 МВт, обороты около 13,4 об/мин; лопасти вращаются.
2. При 0 и 2,9 м/с ротор стоит. При 3 м/с вращается; при 20 м/с мощность 2 МВт. При 25 и 30 м/с — защитная остановка и неподвижный ротор.
3. Проверьте паузу и возобновление, все кнопки камеры и управление с клавиатуры, узкий экран, отсутствие ошибок JavaScript.
4. В браузере без WebGL должно появиться сообщение о недоступности сцены, а слайдер, числа и график должны работать. Проверьте также системную настройку уменьшения движения.

## Допущения

Параметры турбины условные. Cp постоянный, механические и электрические потери не учтены, выше 12 м/с TSR меняется без корректировки Cp. 2 МВт достигаются примерно при 11,3 м/с при стандартной плотности; 12 м/с — отдельный порог ограничения оборотов. Скорость слайдера уже относится к высоте ступицы, поэтому сдвиг ветра к ней повторно не применяется.

Обороты меняются мгновенно: инерция ротора пока не моделируется. Угол обновляется по формуле theta += omega * dt, где omega в rad/s и dt в s. Пауза сцены не меняет физическое состояние. Форма лопастей и рельеф — художественная визуализация, а не аэродинамический расчёт. Освещение и воздушная перспектива статические.
